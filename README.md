# Solo Software Research (IS117)

Research-stage documentation for our IS117 group project: a guide that helps college students and new developers start small, profitable, one-person software businesses.

**Live site:** https://timothy-bailey4-10.github.io/is117-business-research/

**Research question:** What makes small software businesses run by one person profitable, and what do college students and new developers need to start one?

## How to review
1. Pick a finding on the **Findings → decisions** page.
2. Open its source from the **Sources** page and check it.
3. Open a new issue using the **Peer review** template.
4. We record each issue and our decision on the **Review log** page.

## Honesty rules
- Labels on every claim: **Evidence**, **Analysis**, **Assumption**, **Simulated**, **Planned**.
- `[VERIFY: open the source]` means a person still has to check it.
- `[TODO: ...]` means it still needs to be filled in.
- Personas are simulated, not real interviews.

## Commit messages
Start with a verb and mention the issue number:
- `Clarify target audience (#12)`
- `Add Indie Hackers screenshots (#3)`
- `Fix broken source link on Sources page (#5)`

Writing `Fixes #12` in a commit on `main` closes issue 12 automatically.
