Review & decision log

Every peer review issue on GitHub gets a row here, so a reviewer can see what we decided and check the result.

Decision types. Implement: we'll change it. Investigate: we need to look into it first. Defer: valid, but later. Decline: we won't change it, and we say why.

Reviews use the “Peer review” issue template. Commits that fix an issue mention it, for example Clarify target audience (#12).

On small screens, scroll the table sideways.

Each GitHub issue, our decision, the fix and how it was verified

How to read the labels

  • Evidence we saw it in a listed source
  • Analysis our interpretation of evidence
  • Assumption our belief, not yet tested
  • Simulated made up for planning, not real people
  • Planned a check we have not done yet
  • [VERIFY] must be checked against the source
  • [TODO] still to be filled in
